# Рабочая память и резервная копия

## Постоянные пути

- Рабочая папка на компьютере: `C:\Users\lenovo\OneDrive\Документы\ChatGPT\сайт`
- Папка-двойник на Google Drive: `G:\Мой диск\ChatGPT\сайт`
- Сценарий резервирования: `scripts\backup-to-google-drive.ps1`
- Журнал выполнения: `backup-logs\google-drive-backup-ГГГГ-ММ-ДД.log`

## Ежедневное правило

Каждый вечер в 21:00 Windows запускает задание `ChatGPT-Daily-Google-Drive-Backup` и копирует в папку-двойник новые и изменённые файлы рабочего проекта. Если компьютер был выключен, задание должно выполниться после следующего включения.

Копирование не удаляет файлы из резервной папки. Временные каталоги сборки, зависимости и журналы не копируются: `node_modules`, `.next`, `.pnpm-cache`, `.pnpm-store`, `backup-logs`. Исходный код, документация, настройки и история Git сохраняются.

## Восстановление

Если компьютер перестал работать, восстановить папку `ChatGPT\сайт` из Google Drive на новый компьютер. До начала работы проверить наличие `.git`, `app`, `lib`, `docs`, `supabase`, `tests`, `package.json` и последних изменений.

## Важно

Рабочий контекст проекта нужно записывать в файлы репозитория, а не полагаться только на историю чата. Существенные решения сохранять в `docs`, а инструкции для помощников — в `AGENTS.md` или отдельном документе внутри проекта.
