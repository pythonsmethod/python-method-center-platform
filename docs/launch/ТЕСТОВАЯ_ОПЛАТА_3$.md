# Тестовая оплата 3 $ — как включить

Для приглашённых тестировщиков из разных стран. Они проходят весь платный
путь по-настоящему — оплата, кабинет, персональный ИИ по своему случаю —
но платят 3 $ вместо полного тарифа.

Где видно после включения:

- **на обычной странице оплаты** `pythonmethodcenter.com/payment` — третьей
  карточкой рядом с «5 недель» и «100 дней», чтобы тестировщик выбирал
  тариф ровно так же, как настоящий клиент;
- **на отдельной странице** `pythonmethodcenter.com/payment/test` — то же
  самое, но с пояснениями для тестировщиков; её нет в меню и в поиске.

Перед публичным запуском тестовый тариф убирается одним движением — см.
последний раздел.

---

## Шаг 1. Прогнать один запрос в Supabase

Supabase → SQL Editor → New query → вставить **только эту строку** и Run:

```sql
alter type public.payment_product add value if not exists 'test_access';
```

Без неё платформа не сможет записать тестовую оплату отдельно от настоящих.

Запускать нужно именно отдельно, одну строку — так требует PostgreSQL для
новых значений такого типа.

---

## Шаг 2. Создать ссылку в Stripe

1. Stripe Dashboard → **Product catalog** → **Add product**
2. Name: `Python Method — тестовый доступ`
3. Price: **3.00 USD**, тип **One-off** (разовый платёж)
4. Save
5. У созданного продукта → **Create payment link**
6. В настройках ссылки:
   - **Allow promotion codes** — можно не включать
   - **After payment** → Redirect: `https://pythonmethodcenter.com/payment/success`
7. Скопировать адрес ссылки

> Сумма должна быть ровно **3.00 USD**. Платформа узнаёт тестовую оплату
> по точной сумме: 2,99 или 3,50 она отправит на ручную проверку.

---

## Шаг 3. Внести ссылку в Vercel

Settings → Environment Variables → **Add New**:

| Имя (Key) | Значение (Value) |
| --- | --- |
| `NEXT_PUBLIC_STRIPE_PAYMENT_LINK_TEST` | адрес ссылки из Stripe |

Sensitive выключить — это обычный публичный адрес.

Затем **Deployments → «…» → Redeploy**.

---

## Что получает тестировщик

- Оплата 3 $ проходит через настоящий Stripe — заодно проверяется, работают
  ли карты его страны.
- Оплата записывается автоматически (через вебхук), в Telegram приходит
  сигнал, в кабинете основателя видна строка «Тестовый доступ (3 $)».
- Открывается **платный уровень платформы на 14 дней**: кабинет, загрузка
  документов, чат с командой и персональный ИИ, работающий с его случаем.
- Сопровождение Professor Python в это не входит — на странице так и
  написано прямым текстом, чтобы никто не ждал разбора анализов за 3 $.

---

## Что написать тестировщикам

> Привет! Помоги, пожалуйста, проверить нашу платформу.
> Пройди путь как обычный человек: зарегистрируйся, заполни анкету,
> загрузи любой документ, оплати тестовый доступ за 3 $ вот здесь —
> pythonmethodcenter.com/payment/test — и посмотри кабинет и ИИ-помощника.
> Напиши мне, что было непонятно, что не открылось и где ты растерялся.
> Если оплата не пройдёт — обязательно скажи, из какой ты страны: это
> тоже важный результат.

---

## Когда тест закончится (перед запуском в мир)

Удалить переменную `NEXT_PUBLIC_STRIPE_PAYMENT_LINK_TEST` в Vercel и сделать
Redeploy. Карточка «Тестовый доступ» сразу исчезнет со страницы оплаты, и
отдельная страница перестанет предлагать оплату. Код трогать не нужно. В Stripe можно
деактивировать ссылку (Payment link → «…» → Deactivate).

Тестовые оплаты останутся в базе под отдельным названием «Тестовый доступ
(3 $)» — их видно отдельно и они не смешиваются с выручкой.
