# Перед фокус-группой: что пройти руками

Этот список закрывает разрыв между тем, что можно проверить в коде, и тем,
что ломается только на живом сайте. Всё, что здесь есть, за один день
поймало четыре поломки, невидимые для тестов и сборки: кабинет не
открывался целиком, три формы падали по нажатию кнопки, адрес не
сохранялся, а описание бесплатной услуги противоречило договору.

Пройти нужно **одним человеком на живом сайте до того, как придёт группа**.
Занимает около сорока минут.

---

## 0. Применить миграцию магазина

Единственная неприменённая миграция:
`supabase/migrations/20260806090000_shop_waitlist.sql`.
Как — в `docs/deployment/SHOP_WAITLIST_DEPLOYMENT_2026-08-06.md`.

Проверка: `select count(*) from public.shop_waitlist;` возвращает `0`.

Без неё лист ожидания магазина не сохраняет заявки, но и не теряет их —
они уходят в Telegram с пометкой, что в базу не записались.

---

## 1. Регистрация — новым адресом, не своим

- [ ] Зарегистрироваться на **новый** email, которого нет в базе.
- [ ] Письмо подтверждения пришло. **Проверить папку «Спам»** — если оно
      там, для группы это критично, скажите мне.
- [ ] Вход по ссылке из письма работает.

## 2. Анкета

- [ ] Заполнить и отправить.
- [ ] Обе галочки согласия обязательны — форма не даёт отправить без них.
- [ ] После отправки открывается кабинет, а не пустая страница.

## 3. Кабинет — каждый раздел открыть

- [ ] Главная кабинета
- [ ] Мой кейс
- [ ] Мои документы
- [ ] Динамика
- [ ] Мои добавки
- [ ] Токены
- [ ] Связь с центром

Любая страница с надписью «Страница не открылась» — прислать мне код
ошибки, он однозначно указывает на причину.

## 4. Формы — именно нажать «Сохранить» и вернуться

Это то место, где всё ломалось. Мало открыть страницу — надо сохранить,
**уйти на другую страницу и вернуться**, и увидеть, что данные на месте.

- [ ] Мой кейс → имя, телефон, адрес доставки → сохранить → уйти →
      вернуться → адрес на месте
- [ ] Динамика → внести показатель вручную → появился на графике
- [ ] Мои добавки → добавить добавку с временем → появилась в расписании
- [ ] Мои добавки → отметить приём → отметка держится после обновления
- [ ] Связь с центром → отправить сообщение → оно видно в переписке

## 5. Загрузка документов

- [ ] Загрузить файл в «Мои документы» → он появился в списке
- [ ] Открыть его по ссылке → файл открывается

## 6. Распознавание анализов — самое непроверенное

Эта функция написана вчера и **ни разу не встречалась с настоящим
бланком**. Проверить обязательно до группы.

- [ ] Динамика → скрепка → сфотографировать реальный бланк анализа
- [ ] Помощник вернул показатели, а не ошибку
- [ ] **Цифры совпадают с бланком** — сверить построчно
- [ ] Сохранить отмеченные → появились на графике
- [ ] Загрузить второй бланк другой даты → появился блок «Что изменилось»
- [ ] В ответе помощника **нет** оценок и рекомендаций

Если распознавание врёт в цифрах — сказать мне, и до группы я закрою
скрепку, оставив ручной ввод.

## 7. Помощник

- [ ] Спросить на главной, не входя в аккаунт — отвечает
- [ ] Спросить в кабинете — отвечает и знает про ваш кейс
- [ ] Спросить «что входит в бесплатный разбор» — ответ совпадает со
      страницей «Бесплатный разбор»
- [ ] Попросить рекомендацию по добавкам — **отказывает** и отправляет к
      Professor Python

## 8. Красный флаг — проверить, что доходит

- [ ] Написать помощнику фразу с признаком угрозы состоянию
- [ ] Помощник дал безопасный ответ с номерами экстренных служб
- [ ] **В Telegram пришло оповещение команде** — если нет, для группы это
      блокирующая проблема

## 9. Оплата — тестовым доступом за $3

- [ ] Открыть `/payment/test` (прямая ссылка, в меню её нет)
- [ ] Обе галочки, оплатить настоящей картой
- [ ] Деньги списались
- [ ] **В кабинете открылся платный доступ** — это проверка вебхука
- [ ] В Telegram пришло оповещение об оплате

Если доступ не открылся — вебхук Stripe не настроен, и платный путь
для группы закрыт.

## 10. Восстановление пароля

- [ ] Выйти, нажать «Забыли пароль», письмо пришло
- [ ] По ссылке пароль меняется, вход новым паролем работает

---

## Что делать с находками

Любую поломку присылайте с кодом ошибки, если он есть. Код ошибки на
странице «Страница не открылась» указывает на причину однозначно — по нему
я нахожу место за минуты, а без него гадаю.
