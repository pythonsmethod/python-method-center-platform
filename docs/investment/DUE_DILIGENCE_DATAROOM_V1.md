# DUE DILIGENCE — чеклист дата-рума

**Дата:** 2026-07-25
**Правило:** дата-рум собирается **до** первой встречи, а не после того, как инвестор попросит.
Задержка с документами на две недели убивает больше сделок, чем плохие цифры.

Формат: закрытая папка (Google Drive / Notion) с доступом по запросу и логом доступов.
Ничего медицинского и персонального о клиентах в дата-руме быть не должно — только
обезличенные агрегаты.

---

**Пункт 1 — самый важный документ всего пакета.** Все ваши материалы ссылаются на «480 кейсов
за 2 года», но фактическая выручка нигде не названа. Инвестор спросит её в первые пять минут.
Не выходите на встречи без этой цифры, выученной наизусть и подтверждённой документом.

## Приоритет 1 — понадобится в течение 1–2 недель после первой встречи

### Финансы

- [ ] P&L за 2 года по годам и кварталам
- [ ] Структура расходов: сколько стоило обслуживание одного клиента вручную
- [ ] Статистика возвратов и чарджбэков за 2 года
- [ ] Средний чек по годам и его динамика
- [ ] Доля повторных клиентов из 480
- [ ] Текущие остатки на счетах и обязательства
- [ ] Выгрузка из Stripe (транзакции, возвраты, споры)

### Юридическое

- [ ] Публичная оферта (актуальная версия) — есть: `docs/legal/`
- [ ] Политика конфиденциальности и обработки данных
- [ ] Политика возвратов — есть: `docs/architecture/REFUND_POLICY_V1.md`
- [ ] Договоры с подрядчиками (разработка, дизайн) с передачей прав
- [ ] Заключение регуляторного юриста по позиционированию (в работе)
- [ ] Документы по формуле: производитель, состав, маркировка, регистрация
- [ ] Страховые полисы (профответственность, ключевое лицо, продукт) — по мере оформления
- [ ] Товарный знак: заявка или регистрация

### Продукт и технологии

- [ ] Доступ к демо-стенду платформы с тестовым кейсом
- [ ] Архитектурная документация — есть: `docs/architecture/` (28 документов)
- [ ] Внутренний аудит готовности — есть: `docs/audits/` **(показывать, не прятать)**
- [ ] Модель безопасности и разграничения доступа — есть: `ACCESS_CONTROL_V1.md`
- [ ] Протокол красных флагов — есть: `RED_FLAG_EVENT_AND_URGENCY_PROTOCOL_V1.md`
- [ ] Дорожная карта на 12 месяцев — есть: `USE_OF_FUNDS_1M_V1.md` §4
- [ ] Перечень поставщиков и стоимость инфраструктуры

### Клиенты и метод

- [ ] 3–5 клиентов, письменно согласившихся поговорить с инвестором
- [ ] 5–7 обезличенных кейс-стади: было / что делали / стало / срок
- [ ] Отзывы и переписки с согласия клиентов, обезличенные
- [ ] Описание метода для внешнего читателя (не внутренняя конституция, а 3–4 страницы)
- [ ] Программа сертификации специалистов (черновик достаточно)

### Команда

- [ ] CV обоих основателей
- [ ] План найма с ролями, вилками и сроками — есть: `USE_OF_FUNDS_1M_V1.md` §2
- [ ] Описание распределения ответственности

## Приоритет 2 — редко спрашивают на этой стадии, но хорошо иметь

- [ ] Расчёт TAM/SAM/SOM снизу вверх с источниками
- [ ] Конкурентный анализ: 5–7 игроков, позиционирование, цены
- [ ] Маркетинговый план на 12 месяцев по каналам с гипотезами по CAC
- [ ] Когортный анализ (появится после первых месяцев работы платформы)
- [ ] План выхода на англоязычный рынок

---

## Что НЕ класть в дата-рум

- Любые медицинские данные клиентов, включая скриншоты переписок с именами
- Ключи, токены, пароли, содержимое `.env`
- Внутренние документы с оценками конкретных людей
- Незаконченные юридические заключения без пометки «черновик»

---

## Порядок выдачи доступа

1. **До первой встречи:** ничего. Только питч-дек, отправленный письмом.
2. **После первой встречи, если есть интерес:** финансовая модель + use of funds + краткая
   сводка по выручке.
3. **После второй встречи / выражения намерения:** полный дата-рум приоритета 0 и 1
   по подписанному NDA.
4. **Контакты клиентов:** только на финальной стадии, с согласия клиентов, и не более
   3–4 человек — не превращайте своих людей в инструмент.

---

## Контрольный вопрос перед выходом на встречи

Пройдите по списку приоритета 0. Если хотя бы один пункт из 1–7 не закрыт — **встречу лучше
перенести на две недели**. Инвестор, увидевший неготовность на первой же проверке, дальше
читает всё остальное с недоверием, и вернуть это доверие в том же раунде почти невозможно.
