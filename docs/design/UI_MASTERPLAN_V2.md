# UI Master Plan V2

## Intent
The public experience is a private health environment, not a campaign landing page. It combines editorial restraint, resort-like calm, medical credibility, and subtle Egyptian architectural proportion. Professor Python is the public expert; Anham is the persistent platform companion.

## Typography and hierarchy
- Display: Playfair Display, 500–600 weight, tight tracking and compact line height.
- Interface/body: the existing system sans-serif stack, 16–18px body text and 1.6–1.75 line height.
- Eyebrows: 11–12px uppercase, 0.18–0.24em tracking, gold or muted teal.
- Hierarchy: atmospheric page → section narrative → foundation/journey/tool module → action/state → floating Anham.

## Color, light, depth, and shadows
- Obsidian `#090B0C`, deep surface `#0C0F10`, raised surface `#111313`.
- Warm ivory `#F5F0E6`, secondary copy `#AAA79F`.
- Heritage gold `#D8B570`; Anham teal `#82C6C1`.
- Depth uses tonal layers, radial light, translucent 1px borders and broad low-opacity shadows. Egyptian arches are atmospheric geometry only.

## Spacing, cards, and buttons
- 8px base rhythm; 12/16/24/32px controls; 72/96/120/180px sections.
- 1440px desktop maximum with at least 6vw gutters.
- Cards use restrained geometry, one focal object, a fine gold line, and generous internal spacing. Professor Python uses warm mineral light; Anham uses living teal light.
- Primary buttons are gold with dark text; secondary buttons are transparent with ivory text. Minimum control height is 44px.

## Animation
- 300–400ms functional transitions only. No bouncing, aggressive pulsing, or blocking motion.
- Anham’s existing floating conversation follows the viewport. Guest is quiet teal, registered is brighter, and client adds premium gold depth.
- `prefers-reduced-motion` removes nonessential transitions.

## Desktop
- Asymmetrical 60/40 hero; paired foundations and tools; horizontal six-step journey.
- All descriptions remain visible. Navigation and all existing routes remain intact.

## Mobile
- Information and logic are identical; only arrangement changes.
- Cards stack, the journey becomes vertical, buttons become full width, and touch targets stay at least 44px.
- Anham remains reachable as the floating platform companion without obscuring content.

## Character rules
- Professor Python is the only public expert identity.
- Anham is a named companion, never a chatbot or generic assistant icon.
- Guest, registered and client states change her glow, language and perceived finish.
- The current Professor Python visual treatment must later be replaced with his approved real portrait without changing the composition.
