# Единый стиль ответов Анхама

Дата: 2026-09-09. Область: локальная реализация представления ответов, без production deployment.

## A. Что было раньше

Клиентские роли, рабочие роли и специализированные задачи имели раздельные инструкции о тоне. Рабочий разбор прямо требовал нумерованных заголовков с жирным выделением. Только клиентский черновик разбора имел локальную замену длинного тире; общего серверного преобразования Markdown не было. Ответы, сохранённые в истории, могли возвращаться с прежним форматированием.

## B. Что изменилось

`lib/assistant/response-style.ts` задаёт одно правило для русского и английского: естественные короткие абзацы, спокойный бережный тон, перечисление предложениями, отсутствие Markdown и декоративных заголовков. Точность, источник, неопределённость, гипотезы и решение Karen обозначаются обычными словами. Правило не расширяет медицинские полномочия ни одной роли.

`normalizeAnhamResponse` вызывается на сервере перед показом или сохранением текста. Он снимает явное выделение, заголовочную разметку, списки, цитаты и ограждения кода; сохраняет содержимое кода; превращает таблицы в абзацы с названиями колонок. При несовпадении числа ячеек сохраняет заголовки и все значения без выдуманного соответствия. У ссылок остаются подпись и адрес, включая query, fragment и вложенные круглые скобки. Длинное тире заменяется пунктуацией, между числами знаком диапазона, перед отрицательным значением знаком минуса.

Преобразование не переводит, не суммирует и не обрезает ответ. Зачёркнутый фрагмент остаётся явно обозначенным как зачёркнутый, чтобы случайно не превратить отменённую фразу в утверждение. Ответ чата из одних разделителей отклоняется до сохранения. Нормализатор не применяется к source/OCR, извлечённым фактам, JSON целиком, машинным разделителям, пользовательским сообщениям и утверждённым решениям людей. В разборе кейса сначала разбираются два протокольных раздела, затем нормализуются видимые строки. В дайджесте сначала разбирается JSON, затем только перечисленные поля авторского текста RU/EN.

## H. Ограничения

Детерминированная обработка не проверяет смысл ответа модели и не гарантирует его клиническую правильность. Человечность и связность фраз задаются промптом; нормализатор удаляет оформление без смыслового переписывания. Неоднозначные символы, которые могут быть частью значения, формулы, идентификатора или адреса, сохраняются: например `- 5`, `5*10^9/L`, `C#` или fragment URL. Удалять все такие символы без разбора было бы небезопасно. Непарные символы и неизвестный синтаксис не удаляются слепо. Разметка таблицы распознаётся только при наличии строки разделителей. Проверка языка проведена локально на маршрутах и существующих locale-тестах; браузерная приёмка с живыми моделями не проводилась. Поток realtime audio не проходит через этот текстовый нормализатор.

В checkout отсутствуют Master Concept DOCX и упомянутый в AGENTS `CLIENT_PROCESSING_WITHOUT_CLASSIFICATION.md`. Использованы доступные канонические Markdown-документы `docs/ankh/`, CURRENT_STATE/ROADMAP/DECISIONS и правила самого AGENTS; отсутствующее содержание не восстанавливалось по памяти. Retired classification не добавлялась.

## Следующий шаг: изолированная приёмка, 2026-09-09

Этот раздел фиксирует следующий, явно разрешённый владельцем шаг и обновляет статус J–L выше.

**A. До приёмки.** Реализация имела 1039 проходящих тестов; браузерная проверка ещё не проводилась. В checkout нет локальных env-файлов, реальных ключей провайдеров, конфигурации изолированной БД и тестовых учётных записей.

**B. Выполнено.** Создан локальный стенд: настоящий Next dev server и настоящий Anthropic SDK обращаются к HTTP fixture на loopback. Fixture намеренно возвращает Markdown, длинное тире, числа, единицы, референсы, дату и относительную ссылку. Браузер отправляет синтетические сообщения через настоящий публичный чат и `/api/assistant/client`; сервер применяет общий нормализатор, UI показывает обычные абзацы. В каждом из двух финальных запросов провайдер подтвердил наличие общего style-блока и нужной локали.

На главной странице проверены RU → EN → RU, открытие чата, локализованные ввод и отправка. На странице тарифов повторены RU/EN диалоги. Сохранены `<3,2 мМЕ/л` / `<3.2 mIU/L`, `0,4–4,0` / `0.4–4.0`, `09.09.2026` и `/cabinet?sample=3.2#documents`; источник остаётся явно синтетическим, оговорка о необходимости разбора человеком сохраняется. DOM и визуальная проверка показали отсутствие Markdown в ответе.

Выявлен и исправлен дефект переключателя: после клиентского перехода с главной на `/payment` общий layout сохранял старый `path`. Переключатель теперь читает актуальный адрес браузера после записи cookie. Проверено `/payment` → `/en/payment` → `/payment`, в том числе после перехода через меню и с `?sample=3.2#details`. Язык документа, название страницы и навигация соответствуют локали в обоих направлениях. Для маршрутов кабинета без языковых дублей адрес остаётся прежним.

**C. Файлы текущего шага.** Добавлены `scripts/anham-style-acceptance.mjs`, `tests/language-switch-routing.test.ts`, минимальный `output/anham-style-acceptance/provider-checks.json`. Изменены `components/LanguageSwitcher.tsx`, `app/layout.tsx`, `lib/i18n/routing.ts`, комментарии в `lib/i18n/locale.ts`, этот отчёт и CURRENT_STATE/DECISIONS/ROADMAP. Изменения единого стиля из предыдущего шага сохранены.

**D. Данные/схема.** Миграций и записей в БД нет. Стенд не подменяет авторизацию. Сохранённый fixture-отчёт содержит только локаль, порядковый номер и булевы результаты проверки, без текста сообщений или промптов.

**E. Проверки.** Финальный `npm test`: **1055/1055 тестов, 129/129 файлов, exit 0**. Новых маршрутных тестов 16: все 11 публичных языковых пар с query/fragment, четыре закрытых/служебных адреса и изменение адреса после клиентской навигации. Отдельный locale-прогон: 21/21 в двух файлах; style/router: 84/84 в четырёх файлах. `npm run typecheck`, `npm run lint` и `git diff --check`: exit 0. Проверка изменённых React-компонентов не выявила дополнительных замечаний в изменённой логике.

Промежуточный локальный стенд с hostname `127.0.0.1` получал циклический redirect при EN-cookie: Next нормализовал rewrite на `localhost` и повторно входил в middleware. Во время последовательной записи файлов HMR кратковременно сообщал об ещё не добавленном экспорте; после завершения записи, перезапуска и финальных проверок ошибка отсутствует.

**H. Ограничения.** Browser E2E выполнен только для публичного чата. Зарегистрированный/платный клиент, Anna, Karen, история и дайджест проверены mock-интеграционными тестами, без настоящих учётных записей или сохранения в Supabase. Живой провайдер не вызывался, поэтому естественность реальных модельных ответов ещё не оценена. Realtime audio и production build не проверялись.

Страницы тарифов и чат прошли целевые проверки.
