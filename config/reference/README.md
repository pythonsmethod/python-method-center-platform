# Справочные таблицы анализа

Справочные файлы, которые читают модули разбора анализов.
Читаются в одном месте — `lib/reference/tables.ts`. Больше нигде.

| Файл | Что содержит | Кто читает |
|---|---|---|
| `analyte_units.json` | канонические единицы, множители, отпечатки референсных интервалов | определитель единиц |
| `biological_variation.json` | естественный разброс показателя и порог значимого изменения | порог значимости |
| `interpretation_blockers.json` | показатели, которые не читаются без спутника | проверка интерпретируемости |
| `unit_aliases.json` | написания единиц в бланках разных стран | определитель единиц |
| `analyte_labels.json` | подписи показателей в бланках и их коды | словарь показателей |

## Почему это данные, а не код

Множитель и величина биологической вариации — клинические факты,
которые подписывает врач. Факт, лежащий внутри функции, — это факт, который
никто не может проверить. Расширение таблицы означает правку JSON и никогда
не означает правку логики.

## Правила

**Ни одно значение отсюда не дублируется в коде.** Если понадобилось число
из таблицы — оно берётся через `lib/reference/tables.ts`.

**Каждый файл объявляет свою версию** в `_meta.version`. Версии всех файлов
складываются в одну строку и записываются рядом с каждой интерпретацией:
без этого невозможно сказать, что именно изменилось, когда результат поехал —
код или таблица под ним.

**Новый показатель добавляется во все нужные таблицы сразу.** Тесты в
`tests/reference-tables.test.ts` не дадут оставить правило или подпись для
показателя, которого нет в справочнике единиц: сравнивать было бы не с чем.

## Статус данных: проверены не полностью

Значения взяты из общей клинической практики и до боевого запуска обязаны
быть сверены:

- `biological_variation.json` → база EFLM Biological Variation Database;
- `analyte_units.json` → прогон на реальных обезличенных документах центра.

## Чего здесь нет намеренно

Таблицы критических порогов и автоматической тревоги. Центр занимается
реабилитацией и восстановлением, а не неотложной помощью: человеку, которому
плохо сейчас, нужна скорая, а не платформа, которая это заметит. Обещать
автоматическую тревогу значило бы обещать то, чего центр дать не может, —
поэтому «скрининг безопасности» из спецификации не построен и не будет
подключён.
